# watch-alert

한국 중고 시계 사이트를 **하루 3회** 자동 검색해서, 원하는 매물이 새로 올라오면 **텔레그램으로 알림**을 보냅니다. API 유료 결제 없이 무료로 동작합니다.

현재 지원(모두 동작 확인됨):

| 사이트 | 방식 | 로그인 | 클라우드(Actions) |
|---|---|---|---|
| **중고나라** | 브라우저로 검색응답 가로채기 | 불필요 | 가능 |
| **번개장터** | 공개 JSON API | 불필요 | 가능 |
| **바이버(VIVER)** | 공개 JSON API (시계 전문) | 불필요 | 가능 |
| **시계거래소** | 로그인 후 개인매물 API | 최초 1회 | 로컬 권장 |

번개장터·바이버는 API 직접 호출이라 가장 빠르고 안정적입니다. 당근/하이시간 등은 지역·네이버 로그인 제약으로 후순위.

## 동작 방식

- 브라우저(Playwright)로 각 사이트 검색 페이지를 열고, 그 페이지가 받아오는 검색 결과(JSON)를 가로채 매물을 뽑습니다. → 사이트의 봇 차단·서명을 브라우저가 대신 처리하므로 잘 깨지지 않습니다.
- 이미 알림 보낸 매물은 `data/seen.json`에 기록해 **중복 알림을 막습니다**.
- **최초 실행은 알림을 보내지 않고** 현재 매물을 기록만 합니다(알림 폭탄 방지). 다음 실행부터 새 매물만 알립니다.

## 로컬 실행

```bash
npm install
npx playwright install chromium
node index.js
```

키워드는 `config.json`의 `keywords` 배열에서 관리합니다(현재: `브레게 마린`).

## 텔레그램 알림 설정

1. 텔레그램에서 **@BotFather** 에게 `/newbot` → 봇 토큰 발급.
2. 만든 봇과 대화 시작 후, 아래로 chat_id 확인:
   `https://api.telegram.org/bot<토큰>/getUpdates` (봇에게 아무 메시지나 먼저 보내야 나옴)
3. 환경변수로 주입:
   ```bash
   TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=... node index.js
   ```
   미설정 시 알림은 콘솔에만 출력됩니다.

## 하루 3회 자동 실행 (무료 · GitHub Actions)

1. 이 폴더를 GitHub 레포로 push.
2. 레포 **Settings → Secrets and variables → Actions** 에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 추가.
3. 끝. `.github/workflows/check.yml`이 KST 09/15/21시에 자동 실행되고, `seen.json`을 커밋해 상태를 유지합니다. (Actions 탭에서 수동 실행도 가능)

## 시계거래소 (개인매물) — 동작 확인됨

시계거래소는 **개인매물**(라운지 아님)을 로그인 후에만 보여줍니다. 최초 1회 로그인하면 됩니다.

```bash
npm run login:watchexchange   # 실제 크롬 창이 뜸 → 로그인만 하면 자동 저장·종료
```

- 로그인 정보는 `data/wx-chrome-profile`(크롬 프로필)에 저장되고, 검색할 때마다 앱을 잠깐 열어 **토큰을 자동 갱신**합니다. 즉 자주 재로그인할 필요가 없습니다.
- 검색은 개인매물 목록(신규순)을 받아 **키워드로 필터링**합니다. 시계거래소는 서버 키워드 검색이 막혀 있어 이렇게 처리합니다.
- 판매자가 브랜드명을 한글로 안 적는 경우가 많아, 구조화된 스펙(브랜드·패밀리·모델명)과 **한글→영문 브랜드 별칭**(브레게→Breguet 등)으로 매칭합니다. "브레게 마린" → 정확히 브레게 마린만.
- `config.json`의 `sites.watchexchange.enabled`가 `true`면 함께 검색합니다.

### 주의: GitHub Actions 자동 실행

시계거래소는 **구글 로그인 + 로컬 크롬 프로필** 기반이라, 클라우드(GitHub Actions)에서 자동 실행하기 까다롭습니다. 현재 권장:
- **중고나라**는 Actions cron으로 무인 자동 알림.
- **시계거래소**는 이 컴퓨터에서 실행(로컬 cron 또는 `npm run check`). 클라우드로 옮기려면 프로필/토큰을 secret으로 올리고 만료 시 재로그인이 필요합니다.
